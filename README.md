# 📊 Blinkit Supply Chain & Inventory Analytics

## 📌 Overview

This project analyzes Blinkit grocery sales and inventory data using SQL, Python, Microsoft Excel, and Power BI. The goal is to identify sales performance, inventory trends, outlet performance, and customer purchasing patterns through interactive dashboards and business insights.

## 💡 Business Insights

- Regular Fat products generated higher sales.
- Tier 3 locations contributed significantly to revenue.
- Supermarket Type1 outlets achieved the highest sales.
- Fruits & Vegetables and Snack Foods were among the top-selling categories.
